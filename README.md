# KV Tuned Website

A modern one-page website for KV Tuned with a calculator iframe, service overview, reviews, and contact details.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Netlify

Deploy this project by connecting the repository in Netlify and using the included `netlify.toml` build settings.
Build command: `npm run build`
Publish directory: `dist`
